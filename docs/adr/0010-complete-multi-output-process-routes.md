# 工艺路线采用完整多产出候选路线

工艺路线不再按单个最终产品截断生成，而是从输入原料出发，在每个已触达的互斥工艺选项组中选择且只选择一个工艺选项，并递归覆盖所有必达处理节点和必达叶子产出。路线推荐可以用 Li 产品、Ni 产品、Co 产品、Mn 产品、Cu 产品和石墨产品等目标产出类别筛选候选，但候选必须先满足路线完整性和互斥约束，返回的路线产出汇总只归集最终叶子产出；主产品和副产品进入收入侧，废水、废气和废固进入处理成本侧，中间物流不展示也不重复计费。

必达处理节点和叶子产出分开建模：例如混酸焙烧尾气处理仍是混酸焙烧路线中的必达节点，但当前图纸不记录 P38 混酸焙烧尾气处理废气产出。

这个决策取代“按最终产品生成路线”的旧假设，因为图纸中的同级编号节点表示同一父节点下的互斥工艺选择，而不是多个可同时存在的产品路线；同一工艺选择会同时产生主产品、副产品和三废，若按目标产品截断会漏算副产品、废气处理链和三废处置成本。`final_product_id` 类字段只能作为路线代表产品或筛选线索，不能决定工艺路线的完整边界。
