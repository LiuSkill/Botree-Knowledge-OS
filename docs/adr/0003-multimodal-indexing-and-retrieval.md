# 多模态索引采用内容准入与独立视觉召回

文档页面或图片块先按质量形成文本索引、仅视觉索引、仅元数据可发现或等待人工修正的准入结果；视觉内容同时建立整页与局部区域索引，并使用 `Qwen3-VL-Embedding-2B` 生成图文对齐的多模态 Embedding，作为独立在线召回通道，视觉理解模型只处理入围候选，不能用 OCR、图片描述或文本命中后的挂图替代视觉召回。文本、视觉和元数据索引按文档版本统一发布，允许满足覆盖率及关键页面门槛的部分覆盖发布；权限、版本和状态以业务数据库生成的已验证范围快照为唯一事实来源，安全校验失败时拒绝检索，非主召回通道失败时允许显式降级。

分块规则变化时复用未变化的解析及独立视觉产物，对目标知识库执行无旧索引回退的原地完整重建，并通过重建前后源快照校验发现并发变化；当前仅对权限、版本或状态预过滤规则等运行时问答元信息变更执行离线召回门禁，不建设版本发布召回门禁、生产漂移监测或性能验收门槛，但保留各通道可配置超时和耗时记录。
